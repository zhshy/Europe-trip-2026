## 路线

北京 → 阿姆斯特丹（3 晚）→ 布鲁塞尔（2 晚）→ 卢森堡市（1 晚）→ 布达佩斯（2 晚）→ 北京

全程欧铁串联，单段最长约 5 小时 50 分，只前进不回头。

## 回程

- **航班**：国航 CA720 直飞
- **时刻**：10/09 布达佩斯 BUD 13:00 → 10/10 北京首都 T3 04:10
- **耗时**：9 小时 10 分
- **说明**：布达佩斯至北京仅此一条直飞，班期为每周一、四、五；10/09 恰为周五

## 申根签证

停留夜数最多国为**荷兰（3 晚）**，因此必须向荷兰使领馆/签证中心递交申请。向其他国家递交属无效申请。
